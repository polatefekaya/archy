# Architecture contract checklist

Before a new provider, rule, MCP tool, sidecar, or durable table: record bounded context, identity, revision/provenance, compatibility version, AOT dependencies, privacy classification, lock/transaction boundary, failure state, fixture, and advisory/hard-enforcement classification.

The Phase 0 contract set is complete only when the ADRs, capability matrix, bounded-context rules, identity/revision contract, compatibility policy, data/recovery contract, and performance budgets exist and are README-linked.
